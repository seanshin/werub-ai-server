Quick Guide

1. Pipeline — 배치 실행
Pipeline 탭에서 Run Now 클릭
daily_collect — 부족 카테고리 약물 LLM 자동 생성
weekly_interaction — 상호작용 갱신
monthly_denial — 삭감사유 갱신
full_validate — 전체 DB 무결성 검증
Dry Run 체크 시 DB 반영 없이 시뮬레이션
2. Staging — 검토 & 승인
수집된 데이터는 Staging에 대기
4-Layer 검증 통과 시 자동 커밋
검증 실패 건은 수동 Approve/Reject
T1 공인기관 > T2 가이드라인 > T3 수동입력 > T4 AI생성
3. Provenance — 출처 추적
Provenance 탭에서 약물코드 검색
예: D-MER01 → 타임라인 조회
모든 필드별 출처(Tier) 확인 가능
변경 이력 CSV/JSON 내보내기
Confidence 0.0~1.0 (높을수록 신뢰)
API 직접 호출:  POST /api/drug-batch/run 배치 실행  |  GET /api/drug-batch/status 상태 확인  |  GET /api/provenance/drug_codes/{code}/timeline 출처 타임라인  |  GET /api/provenance/summary 전체 분포
