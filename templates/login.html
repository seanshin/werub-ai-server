🧙 학습 가이드
단계별로 따라하면 AI가 똑똑해져요
1학습 재료 준비하기
AI에게 "이건 나쁜 글이야", "이건 괜찮은 글이야" 라고 알려주는 예시를 모아야 해요.

마치 아이에게 "이건 뜨거워, 만지면 안 돼" 라고 가르치는 것과 같아요. 예시가 많을수록 AI가 더 정확하게 판단합니다.
💡 최소 100건 이상 필요해요.
"차단할 글"과 "정상 글"을 골고루 넣어주세요.
관리자가 판정을 수정하면 자동으로 모입니다.
2AI 학습시키기
모아둔 재료로 AI를 학습시켜요.

AI가 재료를 반복해서 읽으면서 "이런 글은 차단해야 하는구나" 하고 배우게 됩니다. 사람이 공부할 때 교과서를 여러 번 읽는 것과 비슷해요.
⚡ 빠른 학습 (~10분): 처음 시도할 때
⚖️ 균형 학습 (~30분): 일반적으로 추천
🎯 정밀 학습 (~60분): 최고 정확도가 필요할 때

💡 학습 중에도 기존 차단 기능은 계속 작동해요!
3성적표 확인하기
학습이 끝나면 AI가 얼마나 잘 배웠는지 시험을 봐요.

100점 만점으로 점수가 나오고, 85점 이상이면 합격이에요. 어떤 종류의 나쁜 글을 잘 찾는지, 어디서 실수하는지도 알 수 있어요.
📊 점수가 높을수록 나쁜 글을 잘 찾아요
📊 정확도가 높을수록 실수로 차단하는 일이 적어요

❌ 틀린 것들을 재료에 추가하면 다음에 더 잘 배워요!
4새 AI 적용하기
시험에 합격한 AI를 실제 서비스에 적용해요.

버튼 하나로 적용되고, 그 순간부터 게시글/댓글/블로그의 유해 콘텐츠 검사가 새로운 AI로 바뀌어요.
🚀 적용 후에도 언제든 이전 AI로 되돌릴 수 있어요

💡 이 과정을 반복할수록 AI가 점점 똑똑해져요!
재료 추가 → 학습 → 확인 → 적용 → 재료 추가 → ...
🔄 학습 사이클
① 재료 모으기 (자동 + 수동)
② AI 학습시키기 (원클릭)
③ 성적표 확인 (85점 이상?)
④ 서비스에 적용
⑤ 사용하면서 실수 발견 → ①로

이 과정이 반복될수록
AI가 점점 정확해집니다! 🎯
