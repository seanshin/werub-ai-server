# v2.125.10 — 일반 비전을 qwen3-vl:8b로 복귀: "빈 응답"의 정체는 비호환이 아니라 사고 예산

날짜: 2026-08-19 | HEAD `a2e8adb`(+후속 문서) | 회귀 **1705**(기준선 1700 +5) · 스모크 **173/173 · 베이스라인 0** · 골든셋 신규 실패 0

v2.118.2는 qwen3-vl:8b를 "vision 응답이 빈 문자열(done_reason=length·reasoning형 채널 미포착)"로 판정하고
minicpm-v로 바꿨다. 오늘 minicpm-v4.5 PoC(v2.125.9 §6)의 부수 관측 — qwen3-vl:8b가 `think:false`를 무시하고
사고를 302~1,286자 쓴다 — 를 따라가 보니 **비호환이 아니라 예산 문제**였다.

## 1. 4설정 × 3과제 (`scripts/poc_vision_qwen3vl_think.py`)

| 설정 | 명함 OCR | 사진 | 두 장 | 사고(자) |
|---|---|---|---|---|
| A generate·think:false·np **300** (통제군=v2.118.2 조건) | 4/5 · 5.8s | **빈 응답**(length) | **빈 응답**(length) | 302 / 937 / 1155 |
| **B generate·think:false·np 2048** | 4/5 · 7.3s | ✅ 0.98 · 11.0s | ✅ 구분 · 0.85 · 11.1s | 302 / 1683 / 1286 |
| C chat·think:false·np 2048 | B와 동일 | 동일 | 동일 | 동일 |
| D generate·`/no_think`·np 2048 | 4/5 | ✅ · **15.0s** | ✅ | 290 / **2982** / 1475 |

- `think:false`도 `/no_think`도 사고를 끄지 못한다(D는 오히려 사고가 늘었다). **사고 토큰은 `num_predict`에서 빠진다** →
  300이면 사고만 쓰다 잘리고 본문 0자. 예산을 올리면 세 과제 모두 정상. 엔드포인트(generate/chat) 차이 없음.
- 사전 등록 5기준(빈 응답 0/3 · 명함 ≥4/5 · 두 장 구분 · 한국어 ≥0.66 · 과제당 ≤16s) → **B가 전부 충족**.

## 2. 2차 표본 (`logs/poc_vision_round2.json` · minicpm-v vs qwen3-vl B)

| 과제 | minicpm-v (현행) | qwen3-vl:8b |
|---|---|---|
| 캐릭터 그림 2장 | 서술은 되나 오류("흰색의 장미를 입고") | 정확·자연스러움 |
| **한글 문단 OCR**(정답 알려짐) | 유사도 **0.19** — 프롬프트를 되풀이해 적음 | 유사도 **0.99** |
| WebP 원본 직접 투입 | 이미지 무시("이명·010-****") | 이미지 무시("비디오를 확인할 수 없다") |

- WebP는 두 모델 다 Ollama에 직접 넣으면 버려진다 → `core/images.py` 서버 트랜스코드가 **여전히 필요**하다(모델 무관).
- v2.125.9 §6과 합치면 현행 minicpm-v는 **명함 이름·직함·회사를 창작**하고 문단 OCR은 안 된다.

## 3. 처치

- `routes/vision.py`: `VISION_MODEL = "qwen3-vl:8b"` · `VISION_FALLBACK_MODEL = "minicpm-v:latest"`(처음으로 폴백이 생겼다) ·
  `_vision_payload()`가 사고형 모델(qwen3-vl 계열)이면 `num_predict ≥ 2048` + `think:false`(무시되더라도 존중하는 후속 모델
  대비) · 200+빈 응답이면 **폴백 1회** → 그래도 비면 502(v2.118.2의 무성 실패 방지 규칙 유지) · 타임아웃 90→180s
  (사고형은 로드 포함 36~42s 실측).
- 🔑 **같은 클래스 전 경로**: `core/meeting_vision.py`는 qwen3-vl:8b를 `num_predict 300`으로 부르고 있었고 빈 content를
  `if content:`로 **조용히 버렸다**(200인데 빈 결과 클래스 — 회의 키프레임 분석이 소리 없이 비었을 수 있다). 2048+think False+
  빈 응답 경고 로그.
