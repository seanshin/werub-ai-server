# v2.125.57 — Training 탭 로더 무성 실패 봉합

기준 v2.125.56 · 발견 경위: v2.125.55 라이브 브라우저 확인 중 콘솔 예외

## 결함

- Training 탭을 열 때마다 `loadTrainingStatus`가 템플릿에 없는 `#trainingStatus`(학습 패널 재설계로 빠짐)에 쓰다 예외 →
  `catch`도 같은 요소에 써서 다시 예외. 예외 지점이 함수 앞부분이라 뒤의 **학습 설정값(허용 시간·GPU 상한 등)과 학습 이력 표가 한 번도 채워지지 않았다**.
- 라이브 실측: `/api/training/runs`는 1건(2026-04-20 `qwen2.5:1.5b`)을 주는데 화면은 "학습 이력 없음" —
  표의 글자 색이 템플릿 기본값(`var(--muted)`)이라 로더가 쓴 문구(`#71717a`)가 아님을 확인(무성 실패 클래스 #1).
  같은 모양의 `#gpuStatus`·`#trainingProgress`·`tp*` 7개도 템플릿에 없다.

## 처치

- 없는 요소는 건너뛴다(`if (el)`), 진행률 블록은 패널이 없으면 그 블록만 건너뛴다(이미 자체 try), 실패 시 표에 사유 표시 + `console.warn`.
- 배포 전 코드에도 같은 호출 2곳 — 이번 메뉴 변경이 만든 결함이 아니다.
