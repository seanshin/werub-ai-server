검증했다 — 결함이 확정된 라벨 표본이므로 그대로 통제군이 된다. 음성 표본은 정답 문장을

## 2. 🔑 원인은 **부분문자열 오매칭**이었다

정답과 오답의 갈림은 **항 하나**다.

```
제87조의2(벌칙) ②  … 제23조제3항 …  → 5년 이하 징역 / 5천만원   ← 정답
제90조(벌칙)      … 제23조제4항 …  → 500만원 이하 벌금        ← 모델이 고른 것
```

같은 제23조인데 ③이냐 ④냐로 형량이 갈리고, 모델은 조번호만 보고 골랐다.
그런데 **애초에 이 질의에 벌칙 근거가 붙지 말았어야 했다.**

```
질의: "전자의무기록으로 진료기록부를 대체할 수 있는가?"
        ^^^^  _DUTY_INTENT_TERMS 의 '의무' 가 위치 2에서 매칭 → 문맥 '전자의무기록으로'
```

**`의무`는 `의무기록`(medical record)의 부분문자열이다.** 이 시스템의 핵심 도메인 용어라
금지·의무형 게이트가 상시 오발동했다.

### 연쇄

1. 게이트 오발동 → `_penalty_backref_chunks`가 **벌칙 조문을 근거에 붙임**
2. 질의가 ③항도 ④항도 묻지 않으므로 `_drop_paragraph_mismatch`는 **설계대로 fail-open**
   (양성 매칭이 없으면 아무것도 버리지 않는다 — 근거 소실이 오귀속보다 나쁘기 때문)
3. 모델이 근거에 있는 벌칙을 **묻지도 않았는데 덧붙이고** 잘못된 항의 것을 고름

📌 **단어 경계 없는 부분문자열 매칭** — 약물명에서 두 번 고친 클래스다
(v2.101/102: `이소트레티노인`의 `노인`, 연결어 `와`가 `와파린`에 오매칭).

### 🐞 진단 도중 두 번 틀렸다

검색 결과 출력 루프가 **10건 중 8건째에서 크래시**했는데, 그 출력을 완전한 것으로 읽고
*"검색 히트에 벌칙 조문이 하나도 없다"* 는 진단을 세웠다. 그 위에
*"청크 경계가 조문 경계와 안 맞아 벌칙 텍스트가 흘러들었다"* 는 2차 진단을 쌓았다.
**둘 다 틀렸다** — 못 본 2건이 바로 그 벌칙 조문이었다.
🔑 **틀린 측정 위에 세운 진단은 틀린 진단을 낳고, 두 번째 것이 더 그럴듯했다.**

## 3. 처치 — **좁히는 방향**

의도 어휘를 세기 **전에** 도메인 복합어를 지운다. 근거를 더 붙이는 게 아니라
붙이지 말았어야 할 곳에서 안 붙인다.

```python
_DUTY_MASK_RE = re.compile(r"(?:전자)?의무기록(?:시스템|사|실)?|의무실|의무관|의무장교")

def _has_duty_intent(question):
    """금지·의무형 질의인가 — **도메인 복합어를 지운 뒤** 의도 어휘를 센다."""
    return any(t in _DUTY_MASK_RE.sub(" ", question or "") for t in _DUTY_INTENT_TERMS)
```

### 검증

| | 결과 |
|---|---|
| 통제군 (양방향 15케이스) | **15/15** — 진짜 의무 질의 8건 전부 발동 · 의무기록 질의 7건 전부 침묵 |
| 게이트 실동작 | `전자의무기록…` → **부착 없음** / `명찰 착용 의무는?` → 제89조·제90조 **부착 유지** |
| 라이브 재현 | **2/5 → 0/8** |
| 회귀 `test_medlaw_duty_intent_mask` | **18** |

참 발생률이 40%로 유지됐다면 8회 무사고 확률은 **1.7%**다. 여기에 **기전이 결정적으로
확인된 것**(게이트가 더는 발동하지 않음)을 더해 판단했다.

회귀에는 **전제도 함께 고정**했다 — 마스크 없는 원래 판정이 이 질의에서 걸린다는 것이
이 처치의 근거이므로, 어휘 목록이 바뀌어 그게 사라지면 테스트가 먼저 빨개진다.

## 4. 🔴 정정 — **종결 판정 두 건을 철회한다**

처치를 검증하려고 같은 프로브를 N=8로 한 번 더 돌렸다. 그러자 **1차에서 0이라
"종결"로 보고했던 두 건이 둘 다 나왔다.**

| 결함 | 1차 | 2차 | 합계 | 상태 |
|---|---:|---:|---:|---|
| id479 명찰 과태료 | 0/10 | **1/8** | **1/18 (5.6%)** | 🔴 미처치 |
| id469 전자의무기록 | 2/5 | **0/8** | — | ✅ 처치 완료 |
| id461 제21조③ 반전 | 0/5 | **1/8** | **1/13 (7.7%)** | 🔴 미처치 |

id461은 정규식이 잡은 것이라 원문을 직접 읽어 확인했다 — **위양성이 아니다.**

> **제③항**: 환자의 동의를 받을 수 없는 상황에서도 **특정한 경우에 한해** … 허용한다

제21조③은 `하여야 한다`(**의무**)인데 재량으로 읽었다. 같은 답변이 뒤에서는 "허용해야
한다"로 쓰기도 해서 **한 답변 안에서 표현이 흔들린다.**

🔑 **저율 확률적 결함이었고 1차의 표본이 작아 못 잡았을 뿐이다.**
같은 날 작성한 세션 보고서에 *"재현 0건은 '결함 없음'이 아니라 '이 표본 크기에서
미관측'이다"* 라고 적어 놓고, **그 문장을 같은 세션 안에서 스스로 어겼다.**

⇒ 두 건은 **미처치로 남는다.** 5~8% 대역이라 처치 전후를 판정하려면 **N=30~50**이
필요하다. 지금 표본으로 처치를 설계하면 효과를 읽지 못한다.
