## 3. P0 측정 (측정 선행)

- **캡1500 토큰 예산**: 대표 3문항 실측 프롬프트 2,912~3,055tok(+생성 1,024=~4,000)
  → **전역 num_ctx 8192 내 안착, num_ctx 변경 불요**.
- **num_ctx 요청별 전환 실측**: 8192↔16384 전환마다 **load_duration ~3s(러너 리로드)**
  — `/ask`만 16384를 쓰면 상주 채팅과 번갈아 호출될 때마다 스왑 churn → 미채택 확정.
- **id134 청크의 추가 진실**: 해당 4,091자 청크는 **청크 자체가 제21조③ 제1호 중간에서
  끝남**(코퍼스 청킹이 조문 경계 무시) — 캡 무한대여도 호2·3은 안 보임.
  이 클래스는 규칙5(정직 생략)가 안전망, **코퍼스 조문 경계 재청킹은 별도 백로그**
  (ChromaDB 재색인 수반, link_lists 인시던트 이력상 신중 계획 필요).
