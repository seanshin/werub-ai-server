# RELEASE v2.124.1 — KPI 타일 클릭 상세 (지표별 모달)

**날짜**: 2026-07-07
**헤드라인**: 품질 모니터의 KPI 타일 15종+히어로 지수를 클릭하면 **지표별 상세 모달** —
정의·판독 규율·질문별 분해(나쁜 값 우선)·질문 드릴다운 연결.

---

## 구성

- **타일 클릭 → 지표 모달**(METRIC_INFO 레지스트리):
  - **정의·판독 규율**: EVAL_GUIDE 요약을 지표별로 — "플래그=트리거이지 확정 아님",
    "MiniCheck 간접 함의 위음성", "검색 게이트 성급 조정 금지", "개조식 혼용 정상" 등
    각 지표를 읽을 때의 주의가 모달 상단에 상시 표기.
  - **질문별 분해 테이블**: 해당 지표의 질문별 값(나쁜 값 우선 정렬)+비고(체크 실패
    항목/교차 불일치/judge flip 항목). **행 클릭 = 기존 질문 드릴다운 모달로 연결**
    (지표→문항→원문 3단 내비게이션 완성).
  - **지수 타일**: qi-1.0 **구성값×가중 기여 분해**(구성별 몇 점 기여했는지) 테이블.
  - 체크리스트 타일: 실패 항목 빈도 칩 추가 표시.
- **API 보강**: quality questions에 차원별 점수(accuracy/helpfulness/safety/fluency)·
  korean_ratio, judge_consistency에 질문별 rows(runs·mean·std·flip_rate·flipped 항목).

## 검증

- js/py 문법(종료코드 직접 확인)·graceful HUP·NRestarts 0. 라이브: API 신규 필드
  (질문별 차원 점수·jc 5행)·페이지 openMetric 배선 확인.

## 영향 / 하위호환

- API 필드 추가만. 타일 클릭은 신규 동작(기존 표시 불변). 판독 규율이 UI에 상주해
  지표 오독(트리거=확정 오해 등) 방지.
