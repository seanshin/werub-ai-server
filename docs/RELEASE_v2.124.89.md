안 그러면 두 체크가 같은 것을 두 번 센다.)

### 🐞 첫 구현이 40/40 미검출이었다 — 한글 음절 블록

```
"아닙니다"에는 "아니"가 없다.   아(U+C544) + 닙(U+B2D9) + 니 + 다
```

받침이 붙으면 **다른 음절**이라 부분 문자열로 안 잡힌다. `아(?:니|닙)`로 교정했다.
