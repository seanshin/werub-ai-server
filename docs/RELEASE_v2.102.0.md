# Release v2.102.0 — 의료 결정적 라우터 확장 (DUR·e약은요 → 모델 무관)

**2026-06-12** | 이전: [v2.101.0](RELEASE_v2.101.0.md)

## 요약

"tool-calling 모델을 14b로 키울까?" 검토 결과 — 14b는 명확한 개선 없음(e약은요 회귀, 노이즈).
**모델 교체(확률적)보다 결정적 라우팅(항상 정확)이 의료 안전에 부합**. v2.101.0 결정적 라우터를
**DUR·e약은요까지 확장**해 의료 경로를 완전 모델 무관화.

## 변경 (`core/medical_router.py`)

- **DUR 결정적 라우팅**: 약물명 추출 + 비식별 환자 컨텍스트(나이·임신) → `dur_check`.
  - ≥2 약물(병용) 또는 1약물+환자컨텍스트일 때만 라우팅. 약하면 None → tool-calling 폴백.
- **e약은요 결정적 라우팅**: 부작용/효능/복용법 의도 + 약명 → `drug_info`.
- **약물명 추출 견고화**:
  - 연결어(와/과/랑) 공백 lookahead — '와'파린 내부 오매칭 방지.
  - 후행 조사 제거(에게/을/를/…) — '임신부에게' → '임신부'(불용어).
  - 숫자 시작 토큰 제외(75세·20주·500mg).
  - 제형 접미 '주'가 '20주'(주차) 오인 방지(숫자 시작 필터).
  - **'이소트레티노인'의 '노인'을 고령으로 오인하지 않음**(단어 경계).
- `dur_check`/`drug_info` 요약 추가.
