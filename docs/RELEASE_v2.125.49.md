## 2. GPU 시간대 프로파일 자동 적용 기본 off

`core/gpu_scheduler`의 off_hours 프로파일(19~08시: 14b 해제→7b 상주)이 **상주 정책(14b)과 충돌**:
워커 재기동(하루 ~7회·max_requests)마다 루프가 14b를 내리고 7b를 올리면 **6초 뒤 시작 예열이 14b를
되올려** 7b를 내쫓았다(09-27 03:52:04 해제→03:52:10 14b 복귀 등) — 프로파일은 **실제로 적용된 적이
없고 적재 3회만 헛돌았다**. 라이브 진실은 상주 정책(평가 judge·heavy 복원도 14b 전제)이므로
자동 적용을 기본 off(config `gpu_schedule_profiles_enabled`). 수동 적용 경로는 유지.
라이브 확인: `GPU Scheduler: 시간대 프로파일 자동 적용 off(상주 정책 우선)`.
