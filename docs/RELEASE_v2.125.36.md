## 2. 🔴 판독이 드러낸 별건 결함 — 한글 2.1% 쓰레기 색인

처치:
1. **교체**: KHIDI 첨부 URL 패턴(`fileDownload?titleId=&fileId=`)으로 같은 게시글의
   hwpx 첨부(fileId=3) 확보 → 정상 파싱(4,380자·한글 50%) → `530076-3-….hwpx`로
   색인(17청크). 검색 실측 top-1 등극 확인. 쓰레기 3청크는 백업 후 삭제+tombstone.
   (fileId=2는 검토의견 양식이라 제외.)
2. **같은 클래스 가드**: `index_files`에 파싱 붕괴 가드 — 본문 ≥500자인데 한글 <5%면
   색인하지 않고 `garbage_skipped`로 보고+로그(무성 드롭 금지).
   🔑 **임계 5%는 실측에서 왔다**: 코퍼스 146파일 전수 한글 비율 분포 = 정상 최저
   11.9%(질병군 범주 표)·붕괴본 2.1% — 깨끗한 분리대역. 500자 미만은 판정 보류.
3. 회귀 3(`tests/test_medlaw_index_garbage_guard.py`): 실사고 형상 차단·표 위주
   정상 최저선 통과·짧은 본문 보류.
