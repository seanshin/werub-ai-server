# v2.124.77 — 과거 플래그 오염 범위 실측 · id451 실결함 특정

> 2026-08-04 · 측정·문서 · 코드 변경 0

`v2.124.75`가 충실도 하네스의 일괄 판정 오염을 봉합했으므로, **과거 플래그 중 몇 %가
아티팩트였는지** 실측했다. 답변이 보존된 플래그 **110건 전수**를 대상으로 했다.

## 1. 설계 — 하네스만 바꾼 대조

같은 답변·**오늘의 같은 근거**에 판정 방식만 다르게 적용해 코퍼스 드리프트를 배제했다.

```
구 하네스 = judge_claims(..., verify_flagged=False)   # 일괄 판정만
신 하네스 = 비지지 판정만 개별 재판정
```

## 2. 결과 — 플래그의 **47%가 아티팩트**

| 지표 | 값 |
|---|---|
| 플래그 소멸 | **52 / 110 (47%)** |
| 충실도 상승 | 48건 |
| 평균 충실도 | 0.791 → **0.907** |
| 잔존 실플래그 | **58건** |

날짜별 소멸률은 100%인 날(08-02·08-03·07-30)과 0%인 날(07-27·07-31)이 섞여 있다 —
**특정 시점의 회귀가 아니라 상시 배경 노이즈**였다는 뜻이다.

> ⚠️ **절반이 아티팩트였지만 절반은 진짜다.** 하네스가 쓸모없었던 게 아니라, 플래그를
> **드릴다운 없이 결함으로 세면 2배 과대평가**된다는 뜻이다. `EVAL_GUIDE` §7의
> "플래그=검토 트리거이지 확정이 아님" 규율이 수치로 확인됐다.

## 3. 🔴 id451 판정 정정 — 실결함이 맞다

`v2.124.75`에서 "id451의 재발은 실체가 없었다"고 적었으나 **과했다.**

- 오늘 재현(N=8·N=10)은 우연히 **전부 아티팩트**였다
- 그러나 과거 21건 중 **13건이 봉합 후에도 실플래그로 잔존**한다
