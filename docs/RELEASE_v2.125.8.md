# v2.125.8 — 법령명 오귀속을 결정적으로 센다 (judge가 못 보는 축)

날짜: 2026-08-18 | HEAD `f7fd775` | 회귀 **1697**(기준선 1683 +14)

충실도 judge가 **원리적으로 보지 않는 축** 하나를 결정적 계산으로 계량하기 시작했다.
그리고 그 탐지기를 만들면서 **통제군을 걸고도 뚫렸다** — 이 세션 다섯 번째 탐지기 오류이자
**통제군을 통과하고도 실패한 첫 사례**다(§3).

---

## 1. 무엇이 안 보였나

충실도 judge는 답변을 주장으로 분해해 **주장의 내용이 근거에 있는가**를 본다.
**어느 법률의 조문인가는 판정 축에 없다.**

2026-08-18 A/B에서 후보 모델의 **법령명 오귀속 8건 중 7건이
`faith 1.000 · 환각 없음`으로 통과**했다. 한 답변은 라벨까지 달아 놓고 만점이었다:

```
법률명: 국민건강보험법
조문번호: 제58조의3(의료기관 인증기준 및 방법등) ③
```

정답은 **「의료법」 제58조의3**이다. 조문 *내용*(4년/조건부 1년)은 근거와 일치하므로
모든 주장이 supported로 잡혔다.

📌 v2.124.8이 봉합한 "발간물 문서제목 오귀속"과 같은 클래스이고
`MEDICAL_LAW_SYSTEM` 규칙 7이 금지하는 그것인데, **지표가 위반을 세지 않았다.**

## 2. 처치 — judge가 아니라 결정적 계산

`core/law_attribution.py` 신설. **LLM을 쓰지 않는다** — v2.124.74에서 형식 판정을
judge에서 순수 함수로 옮긴 것과 같은 분업(judge=의미 / 메트릭=형식).

`core/faithfulness.py`의 `score()` 결과에 `law_misattributed`를 실어 야간 배치
`detail`에 자동 영속된다. ⚠️ **부가 축이라 실패해도 충실도 산출을 막지 않는다**(try/except).

## 3. 🔴 v1은 통제군 7/7을 통과하고도 실전에서 위양성 4건을 냈다

v1은 **근거 청크의 `law_name`** 과 대조했다. 그런데 **법령 본문이 다른 법을 정당하게
인용하는 경우**가 정상적으로 존재한다 — 그 법은 `law_name`엔 없고 **본문엔 있다**.

```
의료법 제82조①   … 「장애인복지법」에 따른 시각장애인 …
의료법 제23조①   … 「전자서명법」에 따른 전자서명 …
의료법 제17조의2  … 「노인복지법」 제34조에 따른 시설 종사자 …
```

v1은 이 넷을 전부 오귀속으로 셌다.

🔑 **통제군 7건(오귀속 3 + 정상 4)에 이 패턴이 한 건도 없었다.**
실전에만 있는 종류라 **통과가 보증이 되지 않았다.**

⇒ 교훈: **통제군은 오답/정답 두 종류로 나누는 것으로 부족하다.** 실전에 나올 수 있는
**패턴의 종류**를 세고 각각 최소 하나씩 들어갔는지 확인해야 한다.
**"정상인데 탐지기 규칙에는 걸릴 것 같은" 경계 사례가 통제군의 핵심이다.**

### v2

근거 **본문 전체**와 대조한다. 그리고 그 패턴을 통제군에 넣어 회귀로 고정했다 —
`test_cross_reference_is_not_flagged`가 이 파일의 핵심이고 **지우면 v1로 돌아간다.**
`test_evidence_must_be_the_body_not_just_metadata`는 호출자가 근거를 메타만 넘기는
실수를 잡는다.

회귀 **14** — 오귀속 검출 3 · 정상 인용 3 · **타법 정당인용 4** · 근거 부재 fail-open ·
일반명사(`방법`·`요법`·`동법`) 제외 · 시행령/시행규칙을 모법으로 접기.

## 6. 🔴 배포 게이트 차단 — 그리고 두 번 틀린 진단

이 릴리즈의 배포 게이트가 `korean[spelling-dwaetda]`에서 **차단**됐다(171/173).

### 진단이 두 번 틀렸다

| 내가 한 말 | 사실 |

| "5/5 결정적 재현" | **다른 문장**으로 잰 것이었다. 통제군 정확한 입력(`드디어 됬다. 정말 기쁘다.`)으로는 **44/44 통과** |

### 진짜 원인 — 로그에 그대로 있었다

```
16:30:05  Preloading default model: qwen2.5:14b        ← 상주 예열(2초 주기)
16:30:06  spellcheck 요청 → 7b(5.2GiB) 로드 시도
          ollama: 7b·14b·외부 요청이 15.5GiB에서 서로 축출

```

`spellcheck()`는 LLM 실패 시 **`success:false` + `error_detail` + 원문**을 200으로 돌려준다
(교정 못 했으면 원문 보존 — 설계 의도). 하네스가 `success`를 안 보고 `code==200 and text`만
봐서 **"답을 못 받음"이 "교정 결과 누락 ['됐다']"로 위장**됐다.

📌 v2.125.4의 "200인데 빈 결과"와 **같은 무성 실패 클래스**다. 기전(게이트 자기 부하·VRAM 공존
불가)은 v2.125.2가 하드웨어 전으로 남긴 그대로라 처치하지 않는다.

### 처치 — 실패의 종류를 가른다

`scripts/smoke_contract.py`: `success:false`면 "응답 → LLM 실패 폴백"으로 기록하고 교정 판정은
건너뛴다. **폴백 자체는 그대로** — 내부 호출자(novel·pipeline)는 전부 `success`를 보고 있었고,
어긴 건 하네스 하나였다. `docs/KOREAN_API_GUIDE.md`에 실패 계약을 명문화했다.

⚠️ 재실행도 실트래픽과 겹칠 수 있다. 다만 이제 겹쳐도 **위장은 안 된다** — 그게 이 처치의 값이다.
재실행 결과: **173/173 · 배포 완료 `7c6b7ba`**.

## 7. 🔴 배선 직후 기준선이 22/40 위양성 → 근거에 라벨을 붙여 봉합

§4의 `0/40`은 **A/B 저장 답변(앞 400자)** 표면값이었다. 배선을 끝내고 **프로덕션 배치**로
첫 기준선을 뜨자 **22/40**이 나왔고 대부분이 `['의료법']`이었다 — 의료법 RAG에서 의료법을
인용한 것이 오귀속일 리 없다. **전부 위양성.**

### 7-1. 배선이 반만 돼 있었다

`score()`는 `law_misattributed`를 계산하는데 **러너의 `detail`이 선택된 필드만 담아**
저장되지 않았다. 계산은 하고 아무도 안 받는 상태였다(`560cc18`으로 두 경로 모두 배선).
📌 **"배선했다"가 "끝까지 흘러간다"는 아니다.**

### 7-2. 🔑 검증한 것과 다른 입력을 배선했다

| | 근거로 무엇을 넘겼나 |
|---|---|
| A/B 검증(`law_attr2.py`) | 본문 **+ 법령 청크의 `law_name`** |
| 프로덕션(`faithfulness.score`) | **본문만** |

`get_evidence_chunks()`가 `h["text"]`만 담고 **메타데이터를 버려서** 근거에 법령명이 없었다.

```
제15조(진료기록부 등의 보존) ① 의료인이나 의료기관 개설자는 …   ← "의료법" 0회
```

실측: 근거 **40/40**이 법령명을 하나쯤 갖지만(타법 상호참조) **`의료법`은 15/40**뿐.
⇒ 정확한 인용이 **25/40에서 오귀속**으로 잡혔다.
📌 v2.125.0 **"페이로드가 같아도 통로가 다르면"** — 함수는 같고 **호출자가 다르다**.
회귀 14건도 전부 "근거에 법령명이 든" 문자열이라 이 격차를 못 잡았다.

### 7-3. 봉쇄 → 처치

1. **봉쇄**(`39c934c`) — 근거에 라벨이 없으면 **판정하지 않는다**(fail-open). 사실상 불활성.
2. **처치**(옵션 A) — `get_evidence_chunks()`가 `/ask` 생성 컨텍스트와 **같은 형식**으로
   라벨을 붙인다. 생성과 평가가 **같은 근거 표현**을 보게 된다
   (v2.124.7 "검색 변경은 양쪽 동시 적용"의 표현 판).
   ⚠️ **발간물은 다르게 표시**한다 — `law_name`이 「국민건강보험법령집」 같은 **문서 제목**이라
   법령명으로 오인되면 v2.124.8 오귀속이 재발한다. 탐지기도 그 라벨을 **매칭에서 제외**한다
   (안 하면 `국민건강보험법`이 부분문자열로 걸려 **진짜 오귀속을 정상으로** 센다).
