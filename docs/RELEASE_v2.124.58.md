## 수정 — `core/faithfulness.py` 수치 충실성 가드

주장은 답변의 분해이므로 답변에 없는 수치를 담을 수 없다. 기존 언어 드리프트 가드(07-22 id275)와 동일 패턴으로 결정적 후처리 추가:

- `_num_values(text)`: 유의 수치 토큰을 값 집합으로 정규화 — "3천만"↔"3,000만" 동일 값, **맨숫자 1자리 제외**(목록 번호 노이즈), **'조'는 스케일에서 제외**(법조문 "제N조" 충돌·이 코퍼스에 조 단위 금액 없음). 조문 번호는 2자리 이상이면 비교 대상(제21조→제12조류 변조도 검출).
- `extract_claims`: 주장 수치 ⊄ 답변 수치면 1회 재추출(개선 시 채택) → 잔존 변조 주장 최종 제외.
- **답변 자체의 오수치는 불변 검출**: 답변이 틀리면 주장에도 같은 값이 실려 통과 → judge가 정상 판정. 가드는 분해 아티팩트만 제거.
