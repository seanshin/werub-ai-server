- **pool 35**(의료법 전 영역): 진료거부·진단서·무면허·결격사유·개설 신고/허가·원격의료·

  태아성감별·리베이트·허위기록·처방전 기재·방사선장치·감염관리·인증·의료법인·면허취소·
  자격정지·대리수령·안마사·상급종합/전문병원.
- **근거 가용성 사전 검증(측정 선행)**: 35/35 전부 retrieval 충분(근거 2,045~10,189자,
  약한 문항 0) — 코퍼스(법령 3단비교+고시+발간물)가 풀 전체를 받침을 확인 후 채택.

## ② 결정적 회전 선택기 (`core/eval_pool.py`)

- 일자 기반 회전: `(day_ordinal×k) % n`부터 k개 순환 — **같은 날=같은 세트**(충실도·품질
  러너가 동일 질문 측정=드릴다운 병합 정합), 재현 가능(랜덤 배제), `ceil(35/5)=7일`
  주기로 풀 전체 커버. 파일 손상 시 core 5 폴백(측정 중단 방지). 회귀 test_eval_pool 7.
