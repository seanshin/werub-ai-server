# v2.124.81 — 벌칙 역참조 게이트 확장 + xref 주석 초점 필터 (35b 강화 ①②)

> 2026-08-04 · `routes/medical_law.py` · 회귀 +14 (1241 passed)

잔존 실결함의 **71%**를 차지하던 벌칙 오귀속 클래스에 두 처치를 넣었다. 오늘 진단한
두 실패 모드(**게이트 미발동**·**주석 방향 반대**)를 각각 겨냥한다.

## 1. ① 게이트 확장 — 금지·의무형 질의

`_penalty_backref_chunks`는 처벌 어휘(`처벌·벌칙·벌금·징역…`)에만 발동했다. 그런데 배치 문항은
**"태아 성감별 고지 금지 **의무**는?"** 형태라 걸리지 않았고, 근거에 벌칙 조문이 없으니 모델이
**생명윤리법 제21조/제98조·의료법 제28조/제104조를 창작**했다.

정작 정답인 제88조의2는 **코퍼스에 있었고 "1. 제20조를 위반한 자"로 정확히 역참조까지** 하고
있었다. **게이트가 좁아서 못 붙여준 것뿐이다.**

`_DUTY_INTENT_TERMS`(금지·의무·위반·제한·준수·책무 등) 추가 · config `medlaw_backref_duty_intent`
(기본 true)로 차단 가능.

## 2. ② xref 주석 초점 필터 — 방향을 뒤집는다

재진단 결과 **필요한 대응은 주석 안에 이미 있었다**(제88조 주석에 제19조, 제87조의2 주석에
제27조제1·5항). 문제는 **형태**였다.

```
종전 : 제88조 → [제19조, 제21조제2항, 제40조의2제4항, … 16~17개]
필요 : 제19조 → 제88조
```

모델이 16~17개 목록에서 자기 조항을 찾아 **역방향으로** 읽어야 했다. 무면허는 제27조 **제1항과
제5항이 둘 다** 실려 있어 아무거나 골랐다(`v2.124.9`가 "항 귀속 관찰"로 남긴 잔여가 이것).

`_xref_focus_articles`(검색된 **행위 조문**의 조번호 집합) 신설 → 교집합만 남기고 방향을 뒤집는다.

```
※ 위 벌칙 조문은 **제20조(태아 성 감별 행위 등 금지) 위반**을 처벌한다
   (원문 자동 추출·항 번호까지 대조하라). 다른 조항 목록은 이 질의와 무관하므로 인용하지 말 것.
```

교집합이 비면 **필터링하지 않는다**(fail-open — 근거를 지우는 것보다 노이즈가 낫다).

## 3. 검증

**두 처치가 정확히 맞물린다**(라이브):

```

초점 필터  → 주석이 "제88조의2는 제20조 위반을 처벌한다" 한 줄로 축약 ✅
```

## 4. ⚠️ 미달 — 정답 벌칙 조를 인용하지는 못했다

창작은 없앴으나 **제88조의2를 인용하지 않고 "벌칙은 근거에서 확인되지 않습니다"**로 답했다.
근거에는 있는데도(컨텍스트 87% 지점) 그렇다. **14b·35b 둘 다 동일**하며, 35b는 명시적으로
"제공된 근거에서 확인되지 않습니다"라고 적었다.

**원인은 검색 노이즈로 보인다.** 35b 답변은 대부분 **상대가치점수 고시** 이야기로 흘렀다 —
이 질의는 오늘 아침 진단한 대로 **5슬롯 중 4개가 발간물 노이즈**다. 벌칙 조문을 테일에 붙여도
모델이 노이즈에 끌려간다.

> 📌 **처치는 "창작 차단"까지 도달했고 "정답 인용"은 검색 품질에 막혀 있다.**
> 다음 병목은 생성이 아니라 **검색**이다(발간물 노이즈 제거·권위 위계 강화).
