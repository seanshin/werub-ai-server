## 1. 🔴 일과성 타임아웃 한 번이 **한 시간짜리 고정 오답**이 되어 있었다

통제군 스모크를 처음 돌리자 `진료기록부의 보존기간은?`이 실패했다. 그런데 **3/3 전부 같은
에러**였고 응답이 **0.006초**에 왔다.

```
answer: "Error: HTTPConnectionPool(host='localhost', port=11434): Read timed out. (read timeout=60)"
```

측정으로 층을 갈랐다:

| 확인 | 결과 |
|---|---|
| GPU·상주 | 14b 상주 10.6/16.3GB · util 0% · 축출 0 |
| 앱 **밖에서** 직접 생성 | **3.1~7.6초** · 정답(`10년`·제15조① 단서 포함) |
| 페이로드 5종(think·keep_alive·options) 분리 | 전부 3~5초 — 원인 아님 |
| 라이브 재요청 | **0.006초** ← 캐시 히트 |

원인은 `_medical_law_cache`(TTL **1시간**)가 **실패 응답까지 그대로 저장**한 것이다.
일과성 실패 1회가 그 질문을 한 시간 동안 고정 오답으로 만든다.

**처치 2건:**

```python
if _gen_failed(response):
    return jsonify({"error": "generation_failed", ...}), 502   # 캐시 미기록
```

- 실패는 **502**로 반환하고 **캐시에 넣지 않는다**(기존: 200 + `answer`에 에러 문자열)
- 에러 본문에서 **내부 주소 제거** — `HTTPConnectionPool(host='localhost', port=11434)`가
  응답으로 나가고 있었다. **`v2.124.25` 에러 위생과 같은 클래스가 이 경로에만 남아 있었다.**
  상세는 서버 로그로만 남긴다.

> 🔑 **실패를 캐시하면 일과성 장애가 영속 장애가 된다.** 재시도로 자연 복구될 것이
> TTL 만료까지 고정된다.

## 3. Phase 0 종료 — 노이즈 정제(0-3) **측정 후 기각**

질의 풀 40문항 · 근거 184청크의 코사인 분포를 수집했다. **임계를 추측하지 않기 위해서다.**

```
origin            n    min    p25 median    p75    max
law3dan         158  0.525  0.616  0.649  0.682  0.774
khidi_notice     22  0.463  0.581  0.600  0.655  0.701
hira_pub          3  0.639  0.639  0.714  0.723  0.723
```

**(a) 관련성 하한 게이트 — 기각.** 중앙값 격차 **+0.047**뿐. 법령 90% 보존 하한에서
비법령 **65%가 살아남는다.** 질의별 상대 규칙(δ)도 연속 분포라 경계가 없다.

> 🔑 **원문 대조가 결정타.** `검사내용 보존기간`에서 **노이즈 0.665**(임상시험 시험물질)와
> **정답 0.678**(제15조)이 **0.013 차이**다. 판별할 것은 유사도가 아니라 **주제 일치**이고,
> 코사인에는 그 정보가 없다.

**(b) 하위 권위 배제 — 기각.** "비법령 = 노이즈" 전제가 **틀렸다.** 원문을 읽으니
`교통사고환자 진료기록 5년 보존`(0.723)·`처방전등록번호`(0.701)는 **실제 보충 근거**다.
일괄 배제하면 근거가 사라진다.

**그리고 지금 할 이유가 없다.** 증상은 35b 고유이고(14b는 같은 근거로 그 고시를 무시),
35b도 간결 규칙 A/B(N=16)에서 **1,249자 → 301자**로 이미 해소됐다. 처치는 검색이 아니라
**생성측에 이미 들어가 있다.**

> ⚠️ 기획 초안의 *"0-3은 35b 도입 여부와 무관하게 이득"* 은 **반증됐다.**
> 근거는 35b 관측 **n=1**이었고, 14b 실사용 통제군은 **16/16**이다.
