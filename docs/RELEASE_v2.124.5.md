# RELEASE v2.124.5 — 서식/양식 청크 억제: 의료법 RAG 근거 오염 봉합

**날짜**: 2026-07-10
**헤드라인**: 품질 지수 하락(84.7 B) 드릴다운으로 근본원인을 확정하고 봉합 — HIRA **진료비확인
서식**(동의서·신청서·위임장)이 법령보다 높은 벡터 유사도로 상위 랭크되어 근거를 오염시키고
judge를 오판시키던 구조적 결함을, 고정밀 서식 필터를 검색·평가 양 경로에 적용해 제거.

## 1. 조사 체인 (측정 → 포착 → 근본수정 → 재측정)

```
품질지수 84.7(B) 하락 (야간 배치)
 → 최악 문항 id 95·96 드릴다운
   → id 96: 배치 시점 일회성 텍스트 절단 (라이브 3/3 재현 안 됨 = 결함 아님)
   → id 95: judge가 "진료비 동의 사항"으로 오판 (checks_rate 0.417 허위 폭락)
     → 근거 추적: get_evidence/_rag_law_search가 진료비확인 양식 청크를 근거에 유입
       → 범위 대조: eval + 프로덕션 검색 **양쪽** 오염 (프로덕션이 더 심함)
         → 규모: 발간물 서식 청크 ~1%가 법령보다 高유사도(0.60 vs 0.23)로 상위
```

- **judge는 환각이 아니었다** — 오염된 근거를 충실히 평가한 것. judge 오판 사유("진료비 확인
  처리를 위한 동의 사항")가 오염 청크(진료비확인 위임장·동의서) 원문과 글자 그대로 일치.
- 이 오염은 v2.124.0에서 추가한 **`ctx_precision`(0.225)** 지표가 이미 계량하고 있던 신호 —
  드릴다운으로 원문을 확정해 폐루프의 검토 단계를 완결.
- **프로덕션 생성은 무사했던 이유**: `_rag_law_search`의 법적 근거 floor가 법령 상위 2건을 강제
  포함시켜 생성기가 정답 조문을 사용 → 답변은 정확. 반면 **eval judge는 floor 방어가 없어 무방비**로
  오염 근거에 앵커링 → 지수가 실제보다 낮게 찍힘.

## 2. 배포된 변경 (라이브)

### 서식 판별 + 억제 (`routes/medical_law.py`)
- **`_is_form_chunk`** — 고정밀 서명. fillable 서식만 True, 실질 조문은 통과:
  - `동의함`+`동의안함`(체크박스 동의) · `[ ]`≥5(순수 체크리스트) · 용지규격(`㎜×`)+서식헤더
    (접수번호/별지서식/서명또는인) · `접수번호`+`처리기간`(신청서 헤더) · `위임자`+`수임자`(위임장)
  - **전수 검증**: pub 216·law 127 캐치 = 육안 확인상 전부 진짜 서식(별지서식·신청서·청구명세서),
    실질 조문 오탐 ~0.
- **`_drop_form_chunks`** — legal은 fail-safe(전량 서식이면 원본 유지=근거 소실 방지), pub는 전량
  제거 허용(법령 floor가 근거 보장).
- 적용점: `_rag_law_search`에서 legal/pub 병합 직전 필터.

### eval 근거 경로 (`scripts/eval_faithfulness.py`)
- `get_evidence_chunks`가 동일 `_is_form_chunk`(단일 소스 import)로 서식 청크 제외 → judge/충실도
  채점 근거 정화.
