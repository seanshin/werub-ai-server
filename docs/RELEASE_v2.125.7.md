# v2.125.7 — 명찰 과태료 정답이 청크 캡 23자 밖에 있었다

날짜: 2026-08-18 | HEAD `9524338` | 회귀 **1683**(기준선 1675 +8) · 스모크 **173/173 · 베이스라인 0**

v2.125.6이 미처치로 남긴 저율 결함 중 **id479 명찰 과태료**를 봉합했다.
결함은 생성이 아니라 **절단**이었고, 처치 후 검증은 **발생률로는 판정되지 않았다**.
그리고 그 판정 불가는 이 릴리즈에서 **처치 자체보다 중요한 발견**이다(§5).

---

## 1. 결함

질의 `"의료인의 명찰 착용 의무는?"` 에 과태료를 **300만원**이라 답한다.

| | 답변 | 정답 |
|---|---|---|
| 조·항 | 제92조 (항 없음) | **제92조③8호** |
| 형량 | 300만원 | **100만원** |
| 요건 | 없음 | **시정명령 불이행 시** |

**항·형량·요건 세 개가 동시에 틀린다.**

## 2. 🔑 원인 — 생성이 아니라 절단이었다

| | 값 |
|---|---:|
| 제92조 청크 길이 | **1,699자** |
| 생성 캡 `_chunk_cap()` | **1,500자** |
| 정답 8호 위치 | **1,523** |
| 캡 밖 거리 | **23자** |

```
8. 제4조제5항을 위반하여 그 위반행위에 대하여 내려진 제63조에 따른
   시정명령을 따르지 아니한 사람        ← 위치 1523. 캡 23자 밖.
```

모델이 보는 것은 청크 맨 위의 `① … 300만원`뿐이다. **③8호는 한 글자도 안 보인다.**
보이는 유일한 금액을 쓴 것이다 — 모델은 틀린 답을 지어낸 게 아니라
**주어진 것 중에서 골랐다.**

📌 **v2.124.6이 캡을 600→1500으로 올려 봉합한 바로 그 클래스**인데
1,699자짜리가 또 걸렸다. **캡 경쟁으로는 안 닫힌다** — 제21조는 4,091자다.

## 3. 처치 — `_focus_ho_tail()`

캡에 잘린 구간에서 **검색된 행위 조문을 가리키는 호**를 **항 헤더와 함께**
원문 그대로 되돌린다. 생성 컨텍스트에 이 형태로 들어간다.

```
[절단 구간에서 되돌린 조항 — 근거 원문 그대로]
  ③ 다음 각 호의 어느 하나에 해당하는자에게는 100만원 이하의 과태료를 부과한다
    8. 제4조제5항을 위반하여 … 제63조에 따른 시정명령을 따르지 아니한 사람
```

🔑 **항 헤더를 반드시 함께 싣는다** — **형량은 호가 아니라 항 머리에 있다.**
호만 되돌리면 8호 문장에는 금액이 없어 여전히 100만원이 안 보인다.

🔑 **숫자를 요약해 주는 게 아니라 원문 조각을 제자리에 되돌려 놓는다.**
📌 v2.124.94가 **기각한** 형량 부기와 여기서 갈린다 — 그때는 주석이 금액을 굵게 실었고
모델이 그걸 그대로 따라 써서 **금지 신호가 6/12 → 12/12로 악화**됐다.
여기서 모델이 읽는 것은 여전히 **법령 원문**이다.

## 4. 검증 — 여기가 이 릴리즈의 핵심이다

| | 처치 전 | 처치 후 |
|---|---|---|
| **id479 명찰** (처치 대상) | 3/40 = **7.5%** · 윌슨 95% [2.6%, 19.9%] | 2/40 = **5.0%** · [1.4%, 16.5%] |
| **id461 제21조③ 반전** (대조군·미처치) | 2/40 = **5.0%** | 3/40 = **7.5%** |

🔑 **대조군이 정확히 반대 방향으로 같은 폭 움직였다**(5.0→7.5 ↔ 7.5→5.0).
**이게 N=40의 노이즈 바닥이다.**

⚪ **발생률로는 판정 불가** — 두 구간이 거의 완전히 겹친다.

✅ **그러나 기전은 바뀌었다.** 배포된 코드로 라이브 **9회**를 직접 호출하니
`100만원` · `제92조제3항` · `시정명령` 이 나왔다.
처치 전에는 이것이 **원리적으로 불가능**했다 — 해당 호가 컨텍스트에
**한 글자도 없었기** 때문이다.

🔴 **플래그된 2건은 원문을 열어 확인했다 — 위양성이 아니다.**
여전히 `제92조 … 300만원` 으로 귀속하고,
`100만원` · `시정명령` · `제92조제3항` 이 **하나도 없다**.

## 5. 🔴 측정 설계가 틀렸다는 기록

처치 전 기준선을 잡으면서 **"구간이 넓다"고 스스로 적어 놓고도**,
**같은 N=40으로 처치 후를 재면 판정이 된다고 생각했다. 안 된다.**

| 필요 표본 | |
|---|---:|
| 7.5% → 절반(3.75%)을 검정력 80%로 잡으려면 | **팔당 N ≈ 600** |
| 실무 가능 여부 | **불가능** |

⇒ **이 클래스는 발생률 A/B로 판정할 수 없다.** 판정 가능한 축은 둘뿐이다.

| 축 | 방법 |
|---|---|
| **기전** | 결정적 확인 — 그 텍스트가 컨텍스트에 있는가, 답변에 그 문자열이 나오는가 |
| **조건부 정확도** | *답변이 과태료를 언급할 때* 어느 조항을 대는가 — **분모가 작아져 더 예민하다** |
