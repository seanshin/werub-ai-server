## 1. 구조

- 순서 없이 쌓인 카드 9장 → 좌측 소메뉴 6개 절(좁은 화면은 상단 칩), 한 번에 한 절:
  **계정·보안**(비밀번호·인증·API 키) · **모델·엔진**(상주 모델·큐 기본 모델·모델 초기화·Ollama 엔진 설정) ·
  **알림**(webhook·최근 알림 5건) · **저장소**(이미지 보관·오브젝트 스토리지 상태 읽기 전용) · **연동·연결**(접속 정보) · **시스템 정보**(버전 히스토리).

## 2. 이관

- **상주 모델 조작부**(모델 선택·전환·지금 반납): Dashboard → 모델·엔진. Dashboard 카드는 상태(정책·대상·현재 적재) + "설정에서 변경 →".
- **큐 기본 모델**·**모델 초기화**(지역·언어·지시문): Models 탭 → 모델·엔진. Models에는 이관 안내 링크, 모델 행 **Init** 버튼·결과는 그대로.
- 상주 모델과 큐 기본 모델을 한 절에 나란히 두고 문구로 구분(v2.125.54 D5의 두 개념 혼동 정리).
