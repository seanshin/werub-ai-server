## 1. 근본 원인 — 본 법령 컬렉션만 L2 거리 공간 (구조적 점수 왜곡)

`medical_law_knowledge`(법령·고시 12,686청크)가 **hnsw:space 미지정(ChromaDB 기본
L2)**으로 생성돼 있었다. 다른 컬렉션(medical_pub_knowledge·notice_knowledge·
werub_docs)은 전부 cosine.

- bge-m3 임베딩은 정규화(norm=1.0 실측) → L2² = 2−2cos → **score = 1−dist = 2cos−1**.
- 실측: 제20조 청크 직접 코사인 0.5497인데 검색 score 0.0994 (2×0.5497−1, 공식 정확 일치).
- **랭킹은 단조라 순서 불변** — 그러나 게이트(min_score 0.33/0.40)·rank-폴백 floor
  0.20·컬렉션 간 권위 병합은 전부 **절대 점수** 기반이라 전부 실해:
  - 법령이 게이트를 넘으려면 실질 cos 0.665 필요(발간물은 cos 0.40) → **구조적 권위역전**.
  - 그간의 증상 계보가 전부 이 위에 있었음: v2.114.1 "제21조 rank-2 score 0.234"(실은
    cos 0.617), id95 서식 오염(양식 0.60[cosine 스케일] vs 법령 0.23[L2 스케일] — 서로
    다른 자로 잰 비교), id175 검색 갭, 이번 id197/id199 ctx_precision 0.0.
