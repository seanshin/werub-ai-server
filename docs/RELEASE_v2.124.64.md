# Release v2.124.64 — 외부 답변 충실도 채점(`--pairs`) + `source` 분리

날짜: 2026-07-30 | 종류: feat(eval) | 배포: GPU graceful HUP(NRestarts 0)

## 배경 — Cerno 회신 A-2의 이행

야간 배치는 **질문만 받아 스스로 답을 생성**한 뒤 채점한다. Cerno처럼 자기 파이프라인으로
답을 만드는 호출자는 이 경로를 쓸 수 없어, 충실도 검증이 미측정으로 남아 있었다
(Cerno 성능 기준선 문서의 한계 4번). 실시간 동기 검증은 질의당 LLM 2회가 붙어 p95 목표·
동시 슬롯과 충돌하므로 **비동기 사후 샘플링**으로 합의했다.

## 1. 입력 — `core/eval_pairs.py`

NDJSON 1줄 = 1건: `{id, question, answer, evidence[], meta}`.

- **한 줄이 깨져도 전체를 버리지 않는다** — 하루치 표본이 오타 하나로 사라지면 안 된다.
  오류는 모아서 출력한다(무성 스킵 금지).
- `evidence` 없으면 거절 — "무엇에 대한 지지"인지가 없으면 충실도를 정의할 수 없다.
- **한 번에 100건 상한**(초과분은 잘랐다고 알림) — 야간 배치 창(03:30)을 밀어내지 않기 위해.

## 2. 채점 — `scripts/eval_faithfulness.py --pairs <file> --source cerno`

- 생성 단계를 건너뛰고 주어진 쌍을 채점. 교차검증(2차 의견)은 동일하게 배칭.
- **검색 품질(ctx_precision 등)은 측정하지 않는다** — 근거를 우리가 뽑은 게 아니라 받은
  것이라, 우리 검색을 채점하는 것이 아니다(빈 값으로 남긴다).

## 3. 🔑 조회 — `GET /api/eval/status?source=cerno` + **외부 격리**

**라이브 검증이 결함을 잡았다.** 처음엔 `source`만 붙여 적재했더니, 외부 제출이
`MAX(ts)`의 최신 배치를 차지해 **우리 기본 대시보드와 품질 지수가 남의 답변 기준으로
바뀌었다**(테스트 2건 넣자 지수 **83.4 → 79.2**).

- 외부 제출은 **`ext:` 접두**로 적재한다(`--source cerno` → `ext:cerno`).
- 기본 조회는 `source NOT LIKE 'ext:%'` = **자체 배치만** 본다.
- `?source=cerno`로 외부 배치만 따로 조회(접두는 서버가 붙여 준다).
